# Jason's Sanitation Data Analysis

This folder contains my contribution to the Chicago sanitation data project.

## Analysis Included
- Sanitation complaints by year
- Complaints by ZIP Code
- Complaints by Community Area
- Complaints by Ward
- Geographic distribution of sanitation complaints

## Data Fields Used
- Creation Date
- Street Address
- ZIP Code
- Ward
- Police District
- Community Area
- Latitude
- Longitude

## Notes
The `Year` variable is created from the `Creation Date` column.

This analysis is intended to identify geographic patterns, complaint concentrations, and changes in sanitation complaints over time.

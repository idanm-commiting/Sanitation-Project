# Real supplied data archives for reproducibility

Place these five ZIP archives in this folder to execute all notebook cells:

- `311_Sanitation_Combined_2010_2026.zip` (266,702 raw rows; 265,891 unique request IDs)
- `Food_Inspections_part_1.zip` (105,162 inspection rows)
- `Food_Inspections_part_2a.zip` (52,581 inspection rows)
- `Food_Inspections_part_2b.zip` (52,582 inspection rows)
- `Food_Inspections_part_3.zip` (105,163 inspection rows)

These are direct copies of the uploaded archives, renamed to consistent input names. The code-only GitHub ZIP does not contain them. The offline ZIP does. These archives were not redistributed publicly via GitHub. Dates through September 2026, not an ongoing live feed.
